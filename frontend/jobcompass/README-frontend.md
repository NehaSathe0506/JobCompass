# JobCompass frontend (goes in the `public` folder)

Pages: index (login/register), dashboard, companies, applications, application (details),
deadlines, follow-ups, interviews, calendar, profile.

Stack: HTML, CSS, JavaScript, Bootstrap 5 (CDN), Chart.js (CDN). Talks to the Express API at /api/*.
Needs internet once per page load for the Bootstrap and Chart.js CDN files.

Run: npm start, then open http://localhost:3000
